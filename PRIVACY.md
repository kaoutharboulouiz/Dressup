# Privacy Policy — Dressup Wardrobe Assistant

This application is used by a single person: its developer.

**Data accessed:** Read-only access to the developer's own Pinterest 
boards and Pins (scopes: boards:read, pins:read).

**Data stored:** Only derived structured data (outfit composition 
patterns: garment categories, colors, styling rules). Pin images are 
processed in memory and never stored.

**Data sharing:** None. No third party receives any data.

**Retention:** Data is stored locally on the developer's machine and 
can be deleted at any time.
